# Security

Please **don't report a security problem in a public issue**. Use GitHub's private report instead:
[Report a vulnerability](https://github.com/mflr0/Arkeyan-Launcher/security/advisories/new) (the repository's
Security tab). Only the owner sees it.

Most useful to report: anything in the launcher's **update** path (what it downloads and checks before running it), the
**kit and game install** (files written outside the launcher's own folders), and the **Toy Box link** between the
launcher and a game.

Say which version and system you used, and how to reproduce it. You'll get an answer, and a fix is made in a release
before the details are made public. Supported version: the latest release.
