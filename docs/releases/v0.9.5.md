Arkeyan Launcher 0.9.5

## Fixes
- Linux, fullscreen: the picture no longer stays black while the sound plays (seen with an NVIDIA driver on Wayland). When the graphics driver refuses the game's frames, the game rebuilds its swap chain, then its window surface, and the picture comes back; the game's log names the driver's answer. The same goes for F3 > Fullscreen. Not yet confirmed on the computer that showed it.
- Linux: the original Wii portal (Spyro's Adventure, Giants) can be written to: when the usual write is refused, the game sends its commands as USB control requests, as on macOS. Not yet tested on that portal.
- The portal chip on the game's page sees Xbox 360 and Xbox One portals on every system, not only Wii, PlayStation and PC portals. Nothing is opened to see them.
- Test the portal: a portal that opens but doesn't answer shows "Found, not answering" and why, in the launcher's language; "The portal doesn't answer" no longer follows a plain "Found". Copy puts every portal's result, with each way the game tried to talk to it, on the clipboard for an issue.
- Giants with a real portal: with a portal that numbers its figures anew each time the game resets it (seen with a Wii Swap Force portal), Giants asked "Please put a Skylander on the Portal of Power" again and again while one was on it. The game now gets the portal's answers before its status reports, so it no longer resets the portal over and over, and a figure the game has read keeps its place across a reset. Checked in every game with a stand-in portal that behaves like that one; not yet on that portal.
- Test the portal: Wii, PlayStation and PC portals that work were missing from the result in 0.9.4 ("No portal found"); they are listed again.
- Test the portal, Xbox 360 portals: "Real portal" only when the portal answers the game's first command; otherwise the result shows what the portal sent, if anything. The game's log says whether the portal ever answers, and on Linux which system driver held it.
- Windows: Test the portal and the game's log list each portal Windows has, with its driver. A Wii, PlayStation or PC portal moved to another driver (WinUSB, libusbK...) by a driver tool is shown with how to give it back to Windows.
- Logs: the game's log starts with the date and time of the run. Settings > Support shows which game's last run **Copy game log** carries, and when; Copy game log and Report a problem carry that run once.
- The portal's model is named after its electronics: "Imaginators-era portal" for the id some Swap Force portals answer too.
- Another edition of a game: **Copy disc details** beside the message copies what a new edition needs (game, IDs, version, region, languages, sizes, the executable's SHA-256 and its game code's, the launcher's version; no file names), for a [New disc edition](https://github.com/mflr0/Arkeyan-Launcher/issues/new?template=new_disc_edition.yml) issue.
- Another edition with the same game code as a supported one (only the disc's header differs: region, media ID, version) is accepted as that edition, by the launcher, the game tools and the game.
- **Find my edition**, beside Copy disc details: the game tools read the disc (downloading them first if needed) and copy a short report for the issue: the disc's IDs, region, languages and fingerprints, whether its game code is a supported edition's, and, when it is other code, which of the game's addresses they found in it. Nothing from the game itself.

## Games
Spyro's Adventure 0.9.11, Giants 0.8.11, Swap Force 0.5.10, Trap Team 0.1.4, SuperChargers 0.1.4, Imaginators 0.1.4.

## Known issues
- FSR 3: a fast-moving character leaves a slight trail.
- Spyro's Adventure on Linux: yellow-green blocks on the grass at a 2560x1440 window.
- Achievements show in English in Dutch, Swedish, Norwegian, Danish and Finnish when the disc has no text in that language.
- Windows Defender may report Arkeyan-Builder.exe, the launcher or a built game as `Trojan:Win32/Bearfoos.A!ml`: a false positive ([why, and what to do](https://github.com/mflr0/Arkeyan-Launcher#windows-defender-alerts)).
- SuperChargers and Imaginators: not tested on Windows or Linux yet.
- The mouse does nothing in the games' own menus.
- Apple Silicon Mac required (M1 or later); the first launch on macOS 15 and later goes through Open Anyway.

## Updating
From 0.6 or later: the launcher updates itself.
